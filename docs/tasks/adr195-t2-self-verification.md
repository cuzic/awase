# ADR-195 T2: 自己検証（段階2）を実装する

**【ADR-196で一部拡張、2026-09-23追記・横断レビューS1】[ADR-196](../adr/196-keymap-learn-truth-priority.md)
決定1aが、本タスクの正答率・縮退率の**計算**に次の要件を追加する（採否の**判定**自体は
[ADR196-T2](adr196-t2-mismatch-adjudication.md)が担当——計算はここ、判定は向こうと役割を

- 正答率 = 正解数 / 予測したステップ数、縮退率 = 予測しなかったステップ数 / 全ステップ数
  （分母が異なる）という定義で算出すること。
- 判定に使う最終ウォークは、予測したステップ数が最低300以上になるようにすること
  （**所要時間の見積もりに反映すること**——下記「実装前に必要な実測」参照）。

## 実装前に必要な実測（横断レビューS2対応）

ADR-196 statusが挙げる実測3件のうち「段階2単独の所要時間」（軽量再検証が5分未満に収まる
かどうか、300ステップのサンプル数が現実的かどうかに影響）は、本タスクが担当する。
[ADR195-T1](adr195-t1-independent-learning-process.md)実機プロトタイプの実測時に、段階1と
分離して計測すること。ADR-195検証計画（`195-...md:580-582`）の「段階2の実測が最初の関門」
もこのタスクが引き継ぐ。

## 背景

[ADR-195](../adr/195-keymap-learn-productization.md)決定・段階2は、T1が学習した表を、
学習に使っていない独立のキー列（ランダムウォーク）で採点し、一段予測の正答率と信頼度を
算出する。CI実機の格子で確立した手法（`score_walk.py`相当）を、T1と同じ独立プロセス・
実時間の枠組みへ移植する。

## 実装対象

1. 独立ランダムウォークによる一段予測の正答率・信頼度の算出ロジックを実装する
   （`awase-keymap-learn`の既存シミュレータ資産を土台にできる）。
2. **「誤りに強い分類」を実装する（round1 M-8、本ADR実装着手の前提）**: 少数派が一定数
   以上のときだけ非決定と宣言する等の仕組み。`awase-keymap-learn/README.md`に
   「未実装」と明記された前提機能であり、これが無いと単発の観測誤り（BUG-153系の
   タイミング問題起因を含む）を非決定セルと誤判定し、予測なしに縮退するセルが不必要に
   増える。
3. **信頼度が低いセルの扱い**: 学習をやり直すか、当該セルを予測しない。**やり直しは
   1回までとする**（round3 m-3、上限が無いと40分の中止基準を超えて回りうる）。1回
   やり直しても信頼度が低いままなら予測しない側に倒す。
4. ATOKは99.6%の実測（`191-calibration-experiments.md`）があるが、Microsoft IME本体は
   独立walkでの採点自体が未実施のため「未確認」のまま扱う。

## 完了条件

- 学習していないキー列での採点ロジックのテスト（シミュレータ上で、既知の表に対する
  正答率・信頼度の期待値を固定する）。
- 「誤りに強い分類」のテスト（少数派の観測誤りが非決定セルへ誤判定されないことを固定）。
- やり直し1回上限のテスト。
