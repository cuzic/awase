# awase v2.0.0

**v2 の最初の正式版です。これにあわせて v1（最後は 1.21.1）の保守を終了します。** 今後、v1 には不具合修正も新機能も入りません。v2 への更新をおすすめします。

## v1 から更新する方へ

- 設定ファイル（`config.toml`）はそのまま引き継げます。
- **これまで効いていなかった設定が、更新すると効き始めることがあります。** キー名の読み方を統一した結果です。昔書いたまま忘れていたキー割り当てが突然動く可能性があるので、心当たりがあれば `config.toml` を確認してください。
- 一部の設定はなくなりました。残っていても無視され、起動時に通知が出ます。
- 無変換・変換キーを 1 回だけ押したときの動作の設定が変わりました。古い設定は自動で新しい形に移されます。
- v1 のアプリ内更新通知では v2 は案内されません。このページからダウンロードしてください。

違いの全体と移行の手順は [v1 から v2 への違いと移行ガイド](https://github.com/cuzic/awase/blob/main/docs/migration-v1-to-v2.md) にあります。

## v2 の主な変更

- **日本語入力（IME）の状態は IME 自身を正とする方式に変わりました。** awase が先回りして IME を操作することをやめ、状態を観察して追いかけます。awase の起動直後に、閉じている IME を勝手に開くこともなくなりました。
- **IME に設定したキー割り当てを読み取り、どのキーが何をするかを自動で判断します。** 半角/全角・漢字・F13〜F24・無変換・変換が「オン」「オフ」「切り替え」のどれかを、Google 日本語入力の設定ファイルや Microsoft IME の設定から読み取ります。
- **IME の反応を自分の環境で学習する機能を追加しました。** キー割り当てを自分で変えていても、「このキーを押すと IME がどうなるか」を実際に試して覚えます。設定画面の較正パネルで確認できます。
- **設定の間違いを黙って無視せず、警告で知らせるようになりました。** 設定画面の保存は、変更した項目だけを書き換え、コメントなどを消しません。
- キーボード入力を受け取れなくなった状態を検知して、自動で復旧するようにしました。
- `config.toml` で矢印キーを指定できるようにしました。

## 主な不具合修正

- Google 日本語入力 + Windows Terminal で、カタカナになったあと、ひらがなキーで戻れなくなる不具合
- Chrome + Google 日本語入力で、他のプログラムに IME を閉じられたあと、ローマ字がそのまま入る不具合
- awase 起動直後の最初の入力で、IME は閉じているのにローマ字がそのまま出る不具合
- Chrome + Google 日本語入力で、ごく速い打鍵をすると入力中の文字が消える不具合
- Google 日本語入力 + Edge で、IME をオフ→オンにしたあと最初の言葉が欠ける不具合
- Microsoft IME で、直接入力の状態から最初にひらがなキーを押すと、かなが半角英数で出る不具合
- 無変換・変換を押す間隔が少し長いと、半角英数になってしまう不具合
- タスクトレイの「学習キャッシュをクリア」が何もしなかった不具合

すべての変更は [CHANGELOG](https://github.com/cuzic/awase/blob/main/CHANGELOG.md) にあります。
