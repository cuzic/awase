## 推奨しない・見送る候補(理由つき)
- F-13(`clear_hook_latches_*` の統合): doc と architecture_guard が「別々に持つこと」を意図して固定している。やるなら guard の作り替えが先で、削減量(約 40 行)に見合わない。

- input_defer / conv_mutation / send_health / lifetime_counter の「似た単調カウンタ」: lifetime_counter.rs の doc が「意味論が違うので統合しない」と明記している。差分を確認した上で C 候補にしない。
- `win32::focus_hwnd_observed`(ADR-246 Q3 の観測専用): `win32::get_gui_thread_info_with_timeout` と形は似るが、前者は `hwndFocus` のみで fallback なし、後者は `hwndActive`/前景窓へ fallback する。意図的な差。観測データが溜まるまでは E にしない(output/mod.rs:1370 の呼び出しは output/ 担当の範囲)。
