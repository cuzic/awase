# ADR-280: 仮名の判定に 3 連(トライグラム)を使うと改善するか(2026-10-25)

コード変更なしの Python 評価。結果は集計値のみで、評価データ・打鍵列はコミットしない。

## 測ったもの

`KanaModel::delta` は `data/ngram_hiragana.csv.gz` の 2 連(6,072 件)だけを使う。表には 3 連(36,930 件、低頻度 score < -10 は除去済み)もあるので、3 連を足した 2 通りを、同じ枠組み(#819 以後の判定: 記号は増分 0 で文脈を切る、親指なし区間、`ja_threshold = 4`、`max_keys = 7`、固定 seed の同じ標本、`docs/tasks/adr280-c0-eisu-threshold-measurement-2026-10-24.md` と同じ)で 2 連と比べた。

- **tri-backoff**: 直前 2 文字が仮名で接頭辞 ab が 3 連の表にあれば `P3(c|ab) = f(abc) / (Σx f(abx) + (V − 列挙数) × floor3)`(表に無い abc は `floor3`)。接頭辞が表に無い・最初の 1〜2 打は 2 連の式。
- **tri-interp**: 同じ条件で `P = 0.7 × P3 + 0.3 × P2`(重み 0.7 は未調整の仮の値)。
- `floor3` = 3 連の最小頻度の 1/10(1.0e-11。2 連の `floor` は 2.0e-16)。背景は共通の `ln(1/N_keys)`。

**尺度の連続性**: 2 連と 3 連の score は別々に最大 = 1 に正規化されているが、`P3` は同じ接頭辞の中の頻度の比なので、正規化の尺度は分子と分母で打ち消される(補正は不要)。尺度に依存するのは `floor3` だけで、表の最小値から作った。確認: 日本語区間の増分は 1・2 打目が 3 モデルで同一(平均 -1.95、-0.33)、3 打目は 2 連 -0.66、tri-backoff -0.26、tri-interp -0.02、最小値は -11.1、-14.9、-11.7。tri-backoff は下側の裾が少し深い(最小 -14.9)が、不連続による暴走(#819 前の -33 のようなもの)は無い。3 連の文脈が揃った 1422 打鍵のうち、接頭辞が表にあり 3 連を使えたのは 1418(99.7%)で、2 連へのフォールバックはほぼ起きない(表に無い abc は `floor3` に落ちる側が実質のフォールバック)。

## 結論

- (a) 3 連は改善する。閾値 14 で、tri-interp は日本語の誤入りを 0.95 → 0.15% に下げ(英文の決まる率は 84.9 → 85.8% で同等)、tri-backoff は誤入り 0.80% のまま英文を 84.9 → 91.7% にする。
- (b) 効く域は誤判定率 0.5〜2% で、同じ誤判定率なら英文の決まる率が +3〜11 ポイント。C0(閾値 14 → 16)は誤入りを半減する代わりに英文を 7 ポイント下げたので、3 連はその代償をほぼ取り戻す大きさ。
- (c) 先頭の 1〜2 打には効かない(同一)。3 打目から効く。
- (d) 悪化は他言語の約 0.1 ポイント以内。
- 手元の評価では、3 連の効果は「あれば有利」の中程度で、閾値の調整(C0)で得られる幅と同程度。実装(表の読み込みの追加 36,930 件、`KanaModel` のフィールド追加)の判断は、この大きさを高いと見るかによる。tri-interp の重み 0.7 と tri-backoff の裾の深さは未調整・未比較(実装へ進むなら重みを掃く)。

## 限界

- 評価データはエージェント生成の文(出典・ライセンス不明、`research-private/v3-eval/`)で、実際の利用者の打鍵ではない。日本語は 1400 文×4 開始位置の相関のある標本で、誤判定の差が 0.3% 未満の違い(0.15 と 0.46% など)は数件の違いで、有意とは言えない。単一の seed。
- 日本語の読みは NICOLA の鍵配列に変換した文。n-gram 表は Wikipedia 由来の読みで、評価データと独立だが、文体は偏る(生成文は丁寧語・業務文が多い)。`tests/fixtures/lang_detect_eval.tsv` は 2 連の分布から作ったので使っていない。
- 他言語・コードの標本も生成データ。実機の journal での再校正は ADR-280 D1 の対象。
- 3 連の表は低頻度を除去済み(score < -10)で、表に無い 3 連を一律 `floor3` にしている。この仮定が実際の稀な日本語の並びでどう効くかは、実データで要確認。
