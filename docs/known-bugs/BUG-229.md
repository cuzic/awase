# BUG-229: belief-v2のtrackが明示操作後も古いまま残り、Engineが誤ってOFFになる

**状態(2026-11-09):** 原因はコードの読みで特定(Opus調査)、修正は未着手。実機は dragonflyg4 で1回観測。

**症状:** 利用者が半角英数のまま離れた窓(Chrome)に戻ったとき、「IME ON だが Engine OFF」になった。
期待動作は「IME ON なら Engine ON」(IME OFFの時だけEngine OFF)で、実IMEは`hiragana`のまま
だったにもかかわらずEngineが`reason=Inactive(NotRomajiInput)`で非活性のままになった。

**タイムライン(UTC, awase.log 2026-11-09T13:13:19)**: ADR-245の「戻った窓の最初の打鍵→半角英数
トグルを復元」が発火しbeliefがkanaへ収束・Engine ON(`z=(mode=kana basis=z-observed-high)`)。
その約70μs後、同じ打鍵(Backspace, vk=0x08)の処理中に`[belief-v2]`が`z=(mode=eisu basis=z-explicit)`
へ食い違いを再開、43ms後に届いた`[mozc-shm]`の`"tsf_mode":"hiragana"`(本物の確認)は無視され、
43ms後にEngineが再度OFFに。

**原因:** `scope_belief.rs::on_explicit`は`track`引数が`Some`のときだけ`row.track`を書き換える
(:369-371)。ADR-245の復元(`InputModeApplied{strategy: UserHalfWidthAlnumToggle}`)が作る
`ScopeEvent::Explicit`は`track: None`(:731-741)なので、復元後も`row.track.conv`は窓を離れる前の
`eisu`のまま残る。直後のBackspace(テーブルキー)の予測は`view.track`(=この古いeisu)を入力にして
効果を予測し(`scope_event_of_prediction`:640-657)、`track: Some(prediction.track)`付きで**改めて
eisuをexplicit主張**してしまう。この新しい主張が170msの確定期限(`settle_ms`)を立て、直後に届く
本物の`hiragana`観測を棄却する(`accepts`、:788-789相当)。`on_observed`は受理した観測で
`row.track.conv = None`へ戻す(:541-543)が、`on_explicit`は対応する掃除をしない――この非対称が
原因。`belief_v2`は既定で有効で、EngineはZ(belief-v2)を読むため、古いeisuがそのままEngine停止に
直結した(BUG-192/ADR-244 M-2が「トグルがアクティブな間」だけ対処した近縁の問題の、別の抜け)。

**再現手順:** 半角英数のまま別窓へ切り替え→元の窓(TSF native, GJI系)へ戻り→最初のテーブルキー
(Backspace等、文字キーでなくてよい)を押す。

**調査:** Opusサブエージェントによるコード読み(commit `6237a0601`)。当初の仮説(言語判定
`ime_on_eisu`のスコアがフォーカス切り替えをまたいで持ち越される)は否定された
(`src/lang_detect.rs`はウィンドウ切替で必ずエピソードを閉じ、非文字キーは「非日本語」の
新規証拠にならない)。
