# BUG-191: 古い ImmCrossProbe が drift 補正を止める(調査済み・方針未決)

**状態(2026-10-06):** CI で再現(`cal-driftrec-refocus-edit-*`、全 6 run)。**方針は所有者判断待ち**(これが「害」か「ADR-191/212 の方針どおり」かが決まらない)。ADR-233(BUG-189)が belief のフォールバックだけを直し、drift 側(`most_recent_trusted_excluding`)を意図的に変えなかった件の続き。

**機序:** `state/drift_correction.rs::evaluate_drift` は、`ConvOpenInference` を除いた「最も信頼できる観測」を `most_recent_trusted_excluding`(**信頼度優先、同信頼度なら新しい方**)で選び、その `age` が `DRIFT_CORRECTION_OBS_MAX_AGE_MS`(1500ms)を超えると `Err(NoDrift::StaleObservation)` で補正を見送る。ImmCross(Standard)の窓では、フォーカス時に記録される ImmCrossProbe(High、`expires_at: None`)が、その後の新しい ObserverPoll(Medium)に常に勝つので、**記録から 1.5s を過ぎると、明示意図があり乖離が続いていても補正が見送られる**。

**測定(診断ログ `[drift-skip] StaleObservation`、run 37561079357):**
- `cal-driftrec-refocus-edit-{gji-atok,msime-native}`(Win32 Edit、Standard、外部から IME を閉じたあとフォーカスを入れ直す)の全 6 run で、`[drift-skip] StaleObservation source=ImmCrossProbe confidence=High age_ms≈4340 observed=false desired=true` が **9 回/run(計 54 回、全て ImmCrossProbe)**。
- 試行ごとの結果: 試行 #0 は drift 補正が 2 回走って回復(`+500ms=True +2000ms=True`)。**試行 #1〜#9(9/9)は補正が 0 回で、+2000ms でも実 IME が閉じたまま**(`+2000ms=False`、打鍵は `typed_blind` の Unicode 注入で出ただけ)。
- `cal-driftrec-edit-*`(フォーカス入れ直し無し)は、観測が 0 件で drift が成立せず(`obs=0 drift=0`)、この件は出ない。
- 別に ObserverPoll(Medium)で `StaleObservation` が 4 回(`tsx-ext-wf-richtextbox-msime`)。

**これが「害」かは未決:**
- 害とする立場: ADR-212 P6 は「**ユーザーの明示操作の書き込みが届かなかったときの再試行だけ**を残す」。明示意図(`explicit_intent==desired`)があり乖離が続く間は再送する設計なのに、古い ICP のせいで再送が止まる。
- 方針どおりとする立場: ADR-191(IME が状態の正で、awase は書かず観測に追随する)・ADR-212(予防的・補正的な actuation の段階撤去)の流れでは、外部で IME が閉じたなら意図の方を捨てて追随し、書き戻さない。ADR-233 も「drift まで A' に揃えると再試行が復活し、awase が実 IME に書く回数が増える(ADR-212 の流れに逆行)」として drift 側を変えなかった。
- いずれにせよ、`cal-driftrec-*` は observe で、`typed_blind` のため verdict は `UNDETERMINED`。実害(ユーザーが閉じた IME のまま打つ)の証拠は無い。

**選択肢(未決):** (1) 現状のまま記録のみ(再開条件: 実機で「外部で IME が閉じた後、awase が書き戻さず入力できない」報告)。 (2) drift の根拠の選び方も ADR-233 の A'(Medium 以上は新しさ優先)に揃える(再試行が復活し、書き込みが増える。ADR-212 の流れに逆行するので ADR と Opus レビューが先)。 (3) 古い ICP を `StaleObservation` の判定から外し、新しい ObserverPoll を根拠にする(=(2) の限定版)。
