# BUG-221: Ctrl 押下中のひらがなキーで belief が OFF のまま残る

**状態(2026-10-26):** 原因の経路は dragonflyg4 の `awase.log` で確定。再現テストは `closed_loop_scenarios.rs::bug220_*`(修正前は赤)。修正は未着手。

**症状:** 「多言語L2をたげんご」と打ったとき、「を」の次の「た」が「え」(素の `E`)になった。

## 観測されたこと(02:36:30 UTC、Windows Terminal×GJI、TSF ネイティブの窓)
- Ctrl+無変換で IME OFF → Ctrl を離す前に F2(0xF2)を押した(`mods c=true`)。
- 通常の F2 は `effective-open-flip → true decided_by=KeyEffectPrediction` で Engine が活性化するが、この F2 は `[mode-key-follow]` の読み直し予約だけで、予測の行も活性化も無い。
- 約 150ms 後の `E`(た)は Engine OFF のまま素通りし、`[gji-obs] candidate SHOW`(IME は ON で組成中)。awase は `StartComposition while engine off — ignored`。
- 約 0.5 秒後、「げ」の右親指(変換 0x1C)の予測が効いて初めて Engine が ON になり、`ge nn go` は正常。BS 5 回で消し直した。

## 原因
`key_effect_predictor.rs::modifiers_suppress_prediction` が、表にあるモードキーでも Ctrl/Alt/Shift/Win 押下中は予測・追跡を止める(`plan_key_effect_track` が `None`)。TSF ネイティブの窓は `read_ime_state_full` が `ime_on=None` で、読み直しでも belief が直らない。
