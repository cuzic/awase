# BUG-187: GJI(ATOK)の外部エコー VK_DBE_HIRAGANA が IME OFF を巻き戻す

**状態(2026-10-05):** 保留(既知の制限扱い)。ADR-181 の症状を、ADR 棚卸しで BUG として起票した。再現・修正は未実施。

**症状(ADR-181、ADR-179 の Passthrough 実験の実機 A/B で発見):** GJI(キーマップ設定=ATOK プリセット)が
VK_DBE_HIRAGANA(0xF2)を `injected=false`(LLKHF_INJECTED なし・awase の自己注入マーカーなし)で
0.4〜28 秒間隔で送ってくる。IME OFF 直後にこれを物理ひらがなキーとして扱い、VK_IME_ON を再送して IME が ON に戻る。

**現状のコード(2026-10-04 確認):** ADR-179 の Passthrough 実験4件は `f3e1212e` で revert、`delegate_to_open_axis` は
ADR-191 で撤去、無変換/変換の単独タップは ADR-206 で役割ベースに再設計。ただし
`runtime/key_pipeline.rs::kp_stage_shadow_ime_toggle` は injected=false の 0xF2 を現在も物理キー扱いする。

**修正時の注意:** foreign-injected な IME モードキーを遮断すると別アプリの機能的キー注入を壊す(BUG-14 の教訓)。
再現は既定の Suppress 設定では起きにくく、Passthrough 設定で可視化された。
