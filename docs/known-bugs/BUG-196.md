# BUG-196: F13〜F24 に割り当てた英数キーの効果に awase が追随しない

**状態(2026-10-10):** 起票。CI で再現し、ADR-247 の修正で CI は解消(実機未確認)。

**症状(外部記事より):** ANSI 配列のキーボードで、物理キーをドライバ側で F14〜F17(無変換=F14、変換=F15、英数=F16、IME ON=F17)に割り当てて awase v2.0.0 を使う。英数入力から親指シフトに戻したとき、Facebook などで親指シフトにならないことがあり、F14 に親指シフトモード切替を持たせて回避した。出典は筆者の note 記事(https://note.com/ja7rhk/n/ne5fed256cd9b)。筆者の `config.toml` と GJI のキー設定は未入手。

**原因(CI で確認):** F13〜F24 は(1)`vk::is_followed_mode_key` に入っておらず直接観測の窓・通過マークが開かない、(2)打鍵時予測の表(`key_effect_table`、13キー)にセルが無く、CUSTOM 表の行も読まない。そのため GJI が F16 で半角英数になっても belief も Engine も更新されない(ADR-199 決定18 は F13〜F24 を開閉の役割の候補に入れたが、モードを SET するキーは対象外)。

**再現(`sc-f16-alnum-chrome-*`、実 Chrome × GJI の CUSTOM 表、F16=半角英数・F17=ひらがな、run 38014850003・38015174713):**
- awase なし: かな→F16 は `ka`(半角英数)、F17 でかなへ戻る。全回 PASS。
- awase あり: かな→F16 で IME は半角英数(`ka`)になるが、Engine が ON のままで `kiu`。400ms 後も同じ(3/3 FAIL)。
- F17 を `keys.ime_on`(awase が IME ON を送る)にすると、F16 の半角英数から戻れず `kiu` のまま(3/3 FAIL)。GJI は開いたままの IME ON でひらがなへ戻さない。

**未確認:** 筆者の症状(かなへ戻したのに Engine が OFF)は逆向きで、同じ根かは未確認。F14 へのモード切替が効いた理由も未確認。

**修正履歴:** `d98c291d`(ADR-247、案2 `is_followed_mode_key` に F13〜F24 + 案1 CUSTOM 表の行からの予測)。CI の A/B(run 38016104665)で修正前相当 3/3 FAIL → 修正後 3/3 PASS、既存 `sc-*` に退行なし(run 38016465418)。実機未確認。

**別件(未修正):** `keys.ime_on` を F17 にすると、F16 の半角英数から戻れない(GJI は開いたままの IME ON でひらがなへ戻さない)。
