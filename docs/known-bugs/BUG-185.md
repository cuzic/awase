# BUG-185: MS-IME の OFF が composition 中は閉じない

**症状:** MS-IME 本体 × 実 Chrome(Imm32Unavailable)/TSF 窓。文字を打った直後(未確定 composition あり)に awase の OFF
(トグルの OFF・無変換単独タップ・Ctrl+無変換)を押すと、実 IME が閉じず半角英数(conv 25→16)に取り残される。ON キーでかなに戻る。

**再現(CI のみ、実機未確認):** `chrome_probe --offrca=1a:typed_nc,ctrl1d:typed_nc`。`1a`/`ctrl1d` とも composition 有りで 0/10、無しで 10/10。
awase なしの OS 注入でも同じ。詳細は `docs/tasks/msime-chrome-off-rca-2026-10-04.md`(R1〜R5)。

**原因:** MS-IME の挙動(composition が残る間の VK_IME_OFF は閉じず conv 変更に化ける)。`IMC_SETOPENSTATUS(0)` は 10/10 閉じる。GJI は影響なし。
ADR-208 決定4 例外(a)の「環境制約」は誤り。

**修正:** ADR-221。`MsImeDirect` の OFF で VK_IME_OFF の後に同期 IMC(OFF) を補う(`ime_controller.rs::msime_close_followup_imc`)。
副作用: composition が取り消される(未確定文字が消える。BUG-184 と同じ症状の側面)。

**回帰テスト:** `key_sequence_policy.rs::post_vk_followup_only_for_ms_ime_close`、`ime_key_sequence_golden.rs`、CI `sc-offrca-fix-*`。

**修正履歴:** 本 PR(ADR-221)。実機確認は未実施。
