# BUG-136: ADR-121のVK_IME_ON冪等再送ゲートのHiragana限定（クローズ）

**クローズ（2026-09-23、コード監査で確認）:** 本バグが対象にしていた
ADR-121 D1（`VK_IME_ON`冪等再送、BUG-37部分対策）そのものが、
2026-09-18のADR-178領域A撤去（`f83084b3`「teardown(tsfnative-rescue):
ADR-121 D1 reassert機構を撤去」）で`key_pipeline.rs`から完全に削除
された。`event.vk_code == VK_DBE_HIRAGANA`というゲート条件自体が
存在しないため、対称化する対象がない。コード修正は不要。

**元の症状（当時の記述の要旨、コード監査で発見・実機未確認のまま）:**
D1のゲート条件が`VK_DBE_HIRAGANA`限定で、同じ関数内で対称に扱われて
いたKatakana/Henkan/Muhenkanの3キーには`VK_IME_ON`冪等再送が効かず、
BUG-37と同型の症状がこれらのキーでは未対策のまま残る、という指摘
だった。D1機構自体の撤去に伴い、この非対称性も解消された。

**関連:** BUG-135と同一の撤去コミットが原因。B37自体（belief一致
だが実IME状態が乖離するBlacklistプロファイル限定の症状）への対策が
今後必要になった場合は、撤去後の現行実装を前提に改めて設計すること
（旧D1の単純復活ではなく）。
