# BUG-220: 戻り待ちのある窓で英数と判定しても入りを見送り、英字がかなになる

**状態(2026-10-25):** 原因はコードの読みで特定、修正を PR にした(実機は未確認)。

**症状:** dragonflyg4(`ime_on_eisu`・`scope=all`・`eisu_threshold=16`)で窓を切り替えながら「function」を打つと、半角英数になる時と、かな(けちめすさくつめ)や一部だけ全角英字(ふんｃちおｎ)になる時がある。journal(2026-10-25 23:43Z、8 試行)は、判定は毎回 `not-japanese`(正しい)で、`action` が `half-width-alnum-entered` と `skipped-toggle-unavailable` に分かれた。

**原因(コードの読み):** `skipped-toggle-unavailable` は `plan_entry_for_language_detect` が `Nothing` を返したとき。belief_open は全て true で、持続トグルは離脱で下りているので、`pending_for_scope`(前面窓の戻り待ち)が真だったと読める。窓 A で入る → B へ離脱(ADR-245: IME へ送らず A を戻り待ちへ) → A へ戻る、で A に戻り待ちが残る。A の実 IME は半角英数のまま。ADR-263 は「二重に入らない」で見送るが、保持した打鍵が流れると、戻り待ちの Resume(最初の打鍵でかなへ復元、ADR-245 決定 3・5)が実 IME をかなへ戻し、英字がかなになる。ADR-263 の保持と ADR-245 の復元が同じ打鍵を取り合っていた。

**修正:** 戻り待ちのある窓で英数と判定したときは、入り直さず戻り待ちから立て直す(`plan_rebuild_from_return_for_language_detect`。注入なし、`ObservedEisu`。ADR-245 決定 8 の RebuildToggle と同じ実行)。`action` は `half-width-alnum-rebuilt-from-return`。日本語と判定したときの挙動(戻った窓の最初の打鍵で復元)は変えない。

**回帰テスト:** `half_width_alnum.rs::bug_220_return_to_window_with_pending_then_english_detected`・`rebuild_from_return_for_language_detect_conditions`。
