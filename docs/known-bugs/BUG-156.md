# BUG-156: appliedとbeliefの食い違いでbeliefトグルの書き込みが飛ぶ

**発見経緯:** 2026-09-21、ADR-191の撤去ブランチのCI `cal-verify-blind`（Editを`Imm32Unavailable`へ降格した読めない条件）のずれが 0%→10〜15%（seed 1・2）に悪化。
復元を外した版(`ci/e2e-blind-b`)は0%に戻るので、原因はADR-189の半角/全角トグルの復元。半角/全角の押下のうち実IMEの開閉が変わった割合は 復元あり 5/8・6/10、なし 8/8・10/10。

**原因（実IMEが変わらなかった7押下の分類）:**
- **A（5件）**: beliefは実IMEと一致（ON）でトグル(true→false)を決めたが、`apply_mechanism`が`[apply-ime] GJI direct: shadow already OFF (open=false), skip`で
  `VK_IME_OFF`を送らない。GjiDirectのalready-matched判定は`applied`（awase自身の直近の書き込み結果、この時点では前回のOFF書き込み）を見るが、beliefは
  その後の予測（`KeyEffectPredicted`、変換キーの`open=Some(true)`等）でONへ動いており、`applied`だけ古い。物理キーはtransportがSuppress済みなので、誰も実IMEを動かさない。
- **C（2件）**: beliefが実IMEと逆（A の連鎖で書き込みが飛んだ後、beliefだけがトグル済み）でトグルし、向きが逆になる。

**修正:** `Runtime::enrich_ime_relevance`（`shadow_action`の唯一の上書き点）で、`belief_conflicts_with_applied(applied, effective_open)`（appliedが既知で、beliefと食い違う）のときは
トグルの`shadow_action`を付けない。すると transport は Allow（Down/Up とも生キーをIMEへ通す）、awaseは書かず、予測・観測が追随する。ユーザー判断（「beliefがズレていたらトグルしない」）。
新しい型・フィールドの追加は無し（純関数1つ＋条件1つ）。`VK_KANJI`(0x19)は`shadow_effect`の静的Toggleなので本修正の対象外（未対応）。
