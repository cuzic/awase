# BUG-166: MS-IME + EDIT の起動直後の Engine OFF(belief ずれ)

**発見経緯:** 2026-09-25。BUG-165 と同じ高速打鍵E2E(`ci/e2e-typing-stress`)の `ts-edit-msime-10ms` で検出。

**症状:** 8 回中 2 回(run 36208885340 の run2、run 36209692627 の run1)で、ローマ字が生のまま入力された(literal 145・154 文字)。awase.log は 2 回とも同じ並び:
- IME ON の約 2.5 秒後に `IME snapshot: ime_on=Some(false) conv=0x19` を観測
- `[key-effect-miss] axis=open predicted=true observed=false` で Engine が deactivated(ImeOff)
- 次の親指キー押下まで約 14 秒 Engine が OFF のまま

**再現率:** `ts-edit-msime-10ms` で 2/8。他の間隔(40/20/5/3/2ms)の edit × MS-IME、multi・rich × MS-IME では再現せず。打鍵速度に依存しない起動直後の現象。

**原因(推測、未検証):** IME belief のずれ(BUG-162/163 と同じ系統の可能性)。ただしハーネスが直前に IME_OFF → ひらがなキーを送るため、**ハーネス誘発の可能性は排除できていない**。

**関連する別件(バグ扱いしない):** 同 run で awase なしの `ts-raw-edit-msime-2ms`(生ローマ字の対照)も 1 回、最初の試行で全 40 文字が消えた。入力先と MS-IME 単体の挙動と推測(断定できない)ため、本バグとは別に扱う。

**次の一手:** ハーネスの IME 切り替え手順を変えても出るかを見て、ハーネス起因か belief の不具合かを切り分ける。記録時点で run の artifact を記録者が直接再確認していない(報告値を転記)。

**原因の見立て(2026-09-26、run 36208885340 の artifact awase.log を直接精査。上の「推測」を更新):** 起動時から実 MS-IME は閉(`ime_on=false`、約11秒間一貫)。
ハーネスの物理 0xF2(36.2s)で awase は `KeyEffectPredicted open=true` により Engine を ON にしたが、**MS-IME 自体は開かなかった**(BUG-152 系: 起動直後の最初の 0xF2 が効かない)。
最初の成功観測(38.96s)が false で Engine OFF。ハーネスの ready 確認は、Engine ON 中に awase が Unicode で出した「か」で通っており**偽陽性**。
以後は IME 閉のまま生ローマ字。52.75s の 変換(0x1C) で実 IME が開き復帰。awase は ADR-191(IME が正)どおり動作しており、awase 本体の修正は不要と判断。
**ハーネス修正:** `typing_stress.rs::ime_ready` に、自プロセスの入力欄の `ImmGetOpenStatus` による実 IME 開閉の確認を追加(閉なら ready 失敗→次候補キーで再試行、3回失敗で abort=INVALID)。
確認: run 36241902201 で `ts-edit-msime-10ms` 18 run × 12 試行が全 PASS(fail=0 loss=0)。旧再現率 2/8 に対し 0/18。
