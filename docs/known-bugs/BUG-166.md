# BUG-166: MS-IME 起動直後の false 観測で Engine が長く OFF

**症状:** `ts-edit-msime-10ms` で 2/8 回、起動直後に `ime_on=Some(false)` を観測し、Engine が約14秒 OFF のまま。ローマ字が生で入る。打鍵速度に依存しない。

**未修正・原因未確定（ログ未入手）。** 有力な仮説: BUG-163 2段目（`c7999ce0`、2026-09-25）の `align_placeholder_desired` が、最初の成功観測が
一過性の false（MS-IME 初期化前）でも `desired_open` をそれへ揃えるため、以後 Engine が false に追随する。それ以前は初期値 true と
drift 補正で ON に戻っていた可能性がある。確認手順: 失敗 run の awase.log で `[startup-align]` の有無と観測源/信頼度、14秒後に何が ON へ戻したかを見る。
`c7999ce0` の前後で同シナリオを比較（bisect）するのが最短。
