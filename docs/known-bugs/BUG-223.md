# BUG-223: 窓切替で `desired_open` の false が持ち越され、観測が無い間 Engine が OFF のまま

**状態(2026-10-26):** 原因の分類と再現テストまで。修正の方針は所有者の判断待ち(実装なし)。

**症状:** dragonflyg4(GJI、awase develop 43359222)で「こうしき」が「るしき」になった(Engine OFF のまま NICOLA の打鍵が GJI のローマ字に処理された)。journal の `effective-open-flip → false` のうち、所有者の IME-OFF キー(`ExplicitIntent`)でない区間が 5 つ(03:48:28・03:49:31・04:33:48・04:34:27・04:37:54Z)。

**原因の分類(コードの読み):**
- (a) 観測が false を出した区間(1: `DeriveMedium{ObserverPoll}` の単独、4: `DeriveHigh(ImmCrossProbe)`)。`desired_open` は true のまま、IMM 系の単独の読みが `resolve_open_at` で勝った(BUG-219 と同型。GJI の tsf-native/imm32-unavailable 窓の IMM の読みは信頼できない)。観測の寿命が切れて `DesiredFallback` の true に戻る。
- (b) 観測が無く `desired_open` に後退した区間(2・3・5)。`reduce_focus_changed`(`ime_model.rs:1157`)は明示意図・観測・applied を捨てるが `desired_open` は捨てない。TSF ネイティブ窓への移動では `on_focus_process_changed`(`focus_tracking.rs`)が「SSOT: desired_open を前窓の値のまま維持」し、キャッシュ復元は hwnd 一致・ON のキャッシュがあるときだけ(`plan_tsf_cache_restore`、BUG-128・BUG-218)。前窓 A で押した明示 OFF が `desired_open=false` として B に持ち越され、B で観測が来るまで `DesiredFallback` の false になる。区間は次の観測・次の窓切替(キャッシュ復元)で終わる。5 の `[half-width-return] effective_open 偽(B から持ち越し)` は同じ持ち越し。

**未確認:** (b) の各区間の直前に、`desired_open` を false にした明示 OFF があったか(ログの 03:49:31・04:33:48・04:37:54Z の前 60 秒の `ExplicitIntent` の flip と `HwndCache`/`[focus]` の行)。区間 3 は区間内に OFF キーの記録が無いので、持ち越し元が区間より前にあるはず。

**再現テスト:** `ime_model.rs::bug_223_explicit_off_in_a_is_carried_into_b_as_desired_fallback`(現状の挙動の固定。修正されたら期待を変える)。

**注意(過去の修正との関係):** 窓切替で ON へ戻す方向の修正は、BUG-128・BUG-218(古い ON のキャッシュ復元が本物の OFF を上書きして Engine だけ ON になる)を再発させうる。
