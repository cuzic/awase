# BUG-223: 窓切替で `desired_open` の false が持ち越され、観測が無い間 Engine が OFF のまま

**状態(2026-10-27):** 修正済み(CI のオラクルで確認、実機は未確認)。ADR-282 の候補 Z(IME の保持単位ごとに最後に受け入れた主張をラッチする belief)を Engine の入力の既定にした(V2-3、#893 `58517793c`)。Z では A の明示 OFF は A のスコープに残り、B は B 自身の主張(無ければ O2 の ON)になるので、`desired_open` の持ち越しで B の Engine が OFF にならない。経緯: #883 `b4bf89603`(スコープごとの追跡)・#884 `4f615cc7c`(shadow)・#891 `b1b5e825b`(切替点)・#892 `db7378e2c`(隠し設定)。
**回帰テスト:** `tests/golden/belief_engine_adopted.txt` の「実機の事故(BUG-223)の列」が全設定で違反なし(`belief_engine_adopted`)。下の `ime_model.rs` の 3 本は旧の belief の挙動の固定(`belief_v2 = false` で旧に戻したときの挙動)で、期待は変えていない。
**戻し方:** `config.toml` の `[general]` に `belief_v2 = false`(旧の belief に戻り、この不具合も戻る)。
**旧の状態(2026-10-26):** 原因の分類と再現テストまで。修正の方針は所有者の判断待ち(実装なし)。

**症状:** dragonflyg4(GJI、awase develop 43359222)で「こうしき」が「るしき」になった(Engine OFF のまま NICOLA の打鍵が GJI のローマ字に処理された)。journal の `effective-open-flip → false` のうち、所有者の IME-OFF キー(`ExplicitIntent`)でない区間が 5 つ(03:48:28・03:49:31・04:33:48・04:34:27・04:37:54Z)。

**原因の分類(コードの読み):**
- (a) 観測が false を出した区間(1: `DeriveMedium{ObserverPoll}` の単独、4: `DeriveHigh(ImmCrossProbe)`)。`desired_open` は true のまま、IMM 系の単独の読みが `resolve_open_at` で勝った(BUG-219 と同型。GJI の tsf-native/imm32-unavailable 窓の IMM の読みは信頼できない)。観測の寿命が切れて `DesiredFallback` の true に戻る。
- (b) 観測が無く `desired_open` に後退した区間(2・3・5)。`reduce_focus_changed`(`ime_model.rs:1157`)は明示意図・観測・applied を捨てるが `desired_open` は捨てない。TSF ネイティブ窓への移動では `on_focus_process_changed`(`focus_tracking.rs`)が「SSOT: desired_open を前窓の値のまま維持」し、キャッシュ復元は hwnd 一致・ON のキャッシュがあるときだけ(`plan_tsf_cache_restore`、BUG-128・BUG-218)。前窓 A で押した明示 OFF が `desired_open=false` として B に持ち越され、B で観測が来るまで `DesiredFallback` の false になる。区間は次の観測・次の窓切替(キャッシュ復元)で終わる。5 の `[half-width-return] effective_open 偽(B から持ち越し)` は同じ持ち越し。

**より強い原因(ログの順序から。追記 2026-10-26):** 区間 3 は直前の操作が F2(ON)だった(04:33:39 `ExplicitIntent` の OFF → 04:33:45 F2 `KeyEffectPrediction` で true → 04:33:48 窓切替で `DesiredFallback` の false)。区間 1・2・4 の前にも同じ型がある。`KeyEffectPredicted`(`ime_model.rs:1057`)は `desired_open` を書かず(`last_intent` を捨て、`key_effect` を置くだけ)、OFF キーの `UserImeSetIntent`(同 902)は `desired_open=false` を書く。この非対称で「OFF キー → F2」は `desired_open=false` のまま `effective_open` だけ予測で true になる。予測は観測の無い窓では寿命が無く(消えるのは settle 後の Medium 以上の観測との照合、次の `UserImeSetIntent`、`FocusChanged`〈同 1175〉)、窓切替で捨てられると `DesiredFallback` の false に戻る。ADR-187 の `ModeKeyPassedThrough { align_desired }`(同 1090)は `derive_any` が値を返すときだけ `desired_open` を揃えるので、観測が無い窓(GJI の tsf-native 等)では揃わない(`kp_stage_mode_key_follow` は通過マークを立てるが、観測が読めない窓では `pass_through_observed` に届かない)。区間 1・4(単独の観測の false)も、`desired_open` が true なら食い違う観測として別に扱えるが、F2 の後で `desired_open` が false のままだった型に含まれる可能性がある(未確認)。

**未確認:** (b) の各区間の直前に、`desired_open` を false にした明示 OFF があったか(ログの 03:49:31・04:33:48・04:37:54Z の前 60 秒の `ExplicitIntent` の flip と `HwndCache`/`[focus]` の行)。区間 3 は区間内に OFF キーの記録が無いので、持ち越し元が区間より前にあるはず。

**再現テスト:** `ime_model.rs` の `bug_223_explicit_off_in_a_is_carried_into_b_as_desired_fallback`(A の明示 OFF の持ち越し)、`bug_223_explicit_off_then_f2_prediction_is_lost_on_focus_change`(OFF → F2 → 窓切替。予測に寿命が無いことも固定)、`bug_223_mode_key_pass_does_not_align_desired_without_observation`(観測が無いと揃わない。観測があれば揃う対照つき)。現状の挙動の固定で、修正されたら期待を変える。

**注意(過去の修正との関係):** 窓切替で ON へ戻す方向の修正は、BUG-128・BUG-218(古い ON のキャッシュ復元が本物の OFF を上書きして Engine だけ ON になる)を再発させうる。
