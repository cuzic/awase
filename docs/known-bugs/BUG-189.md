# BUG-189: Flutter × MS-IME で古い ImmCrossProbe(High,false)が優先され打鍵の途中から全角英字・カタカナに化ける（機序特定・未修正）

**状態(2026-10-06):** CI で再現(awase あり 4 回中 3 回、診断ログ付きの再実行では 8 回中 6 回 FAIL)。**機序を特定し、ADR-233 案 A' で修正を実装(ブランチ fix/bug189-most-recent-trusted)。修正後の CI(run 37463797464): Flutter × MS-IME は 8 回中 PASS 7・INVALID 1(修正前は 1/8 しか PASS しなかった)、LibreOffice は 12 回全 PASS、古い High への反転(`MostRecentTrusted(ImmCrossProbe)`→false)は 0 件。実機未検証。** 別の機序の同形の症状は [BUG-190](BUG-190.md)。GJI は 4 回とも PASS、awase なしの対照(tsx-raw-ext-flutter-textfield-*)は GJI・MS-IME とも 4 回 PASS。

**再現(CI):** ブランチ `ci/e2e-java-office` の run 37425162897(構成 `tsx-ext-flutter-textfield-msime-20ms`、`tools/e2e/input_forms/forms.toml` の `flutter-textfield`)。
Flutter for Windows の TextField(`tools/e2e/input_apps/flutter`)へ MS-IME・awase ありで 20ms 間隔の NICOLA を注入し、UIA で読み戻す。

**症状:**
- 試行の途中から出力が全角英字(期待 `…ねそせくせへひらて` → 実際 `…かねｍぎｇｂｘｙｄ`)やカタカナ(`あぱわの…` → `アパワノ…`)になる。IME の入力モードが途中で切り替わっているように見える。
- 失敗は thumb・mixed の試行が多く、single は崩れない run もある。run ごとに崩れる試行数が違う(2〜4/12)。
- 別 run(37423541905)では ready の 1 文字が `かかか` と重複した。

**機序(診断ログ `[effective-open-flip]`、run 37431493935、flutter-textfield × MS-IME 8 回):**
1. ハーネスの最初の打鍵(IME OFF)をきっかけに FocusProbe が動き、`[ImmCrossProbe] child-hwnd IME=false → High confidence 観測記録`(Flutter の子窓 `FLUTTERVIEW` の cross-process 読み)が 1 件だけ記録される。**この false は記録時点では真の値**(その時 IME は OFF)。`expires_at: None` で残り続ける。後で IME が ON になり ObserverPoll(true)が入っても居座る。
2. 打鍵中は `Skipping observer/SSOT write: typing active` で ObserverPoll(IME=true、Medium)の書き込みが止まる。最後の書き込みから 3.0s(`OBSERVATION_FRESH_WINDOW_MS`)後に `derive_any` が None になる。
3. フォールバックの `most_recent_trusted`(`observation_store.rs`)は `confidence` を先に、`at`(新しさ)を後に比べるため、古い High(false)が新しい Medium(true)に勝つ。実効値が false になり `Engine deactivated (ime=false, reason=Inactive(ImeOff))`。
4. 次の観測(または漏れたキー自身の予測)が入るまでの 0〜2196ms(26 回、中央値 約 20ms)、親指キー(変換/無変換)が `PassThrough` になり MS-IME へ届いて入力モードが切り替わる(全角英字・カタカナ化、出力途中の文字が生キーになる)。
- 反転 26 回中 26 回が `→ false decided_by=MostRecentTrusted(ImmCrossProbe)`。GJI でも ICP=false は記録されるが、打鍵中に OS ポーリングが止まり F2 の `KeyEffectPrediction(true)` が消えないため、プールまで降りず反転しない(偶然に頼った安全)。wx・Qt は ICP の記録自体が 0 件。**LibreOffice × MS-IME にも同じ兆候**(ICP=false、3s 超の空き、`Engine deactivated`)がある。

**修正方針:** [ADR-233](../adr/233-stale-high-observation-beats-newer-in-most-recent-trusted.md)(起草中、Opus round1 反映)。belief のフォールバックだけ、順位キーを `(confidence >= Medium, at)` にする案 A'。drift correction と read_back は変えない。

**次の手順:** ADR-233 を Opus で収束 → 旧・新比較式を並記する診断ログを CI で回して正解率を測る → 修正と回帰テスト(閉ループハーネス/`ime_model.rs` の単体テストで BUG-189 の列を再現)。診断ログ `[effective-open-flip]` は PR #537 に入っている。
