# BUG-189: Flutter × MS-IME で打鍵の途中から全角英字・カタカナに化ける（未調査）

**状態(2026-10-06):** CI で再現(awase あり 4 回中 3 回、診断ログ付きの再実行では 8 回中 6 回 FAIL)。**機序を特定(下記「機序」)、未修正**。GJI は 4 回とも PASS、awase なしの対照(tsx-raw-ext-flutter-textfield-*)は GJI・MS-IME とも 4 回 PASS。

**再現(CI):** ブランチ `ci/e2e-java-office` の run 37425162897(構成 `tsx-ext-flutter-textfield-msime-20ms`、`tools/e2e/input_forms/forms.toml` の `flutter-textfield`)。
Flutter for Windows の TextField(`tools/e2e/input_apps/flutter`)へ MS-IME・awase ありで 20ms 間隔の NICOLA を注入し、UIA で読み戻す。

**症状:**
- 試行の途中から出力が全角英字(期待 `…ねそせくせへひらて` → 実際 `…かねｍぎｇｂｘｙｄ`)やカタカナ(`あぱわの…` → `アパワノ…`)になる。IME の入力モードが途中で切り替わっているように見える。
- 失敗は thumb・mixed の試行が多く、single は崩れない run もある。run ごとに崩れる試行数が違う(2〜4/12)。
- 別 run(37423541905)では ready の 1 文字が `かかか` と重複した。

**機序(診断ログ `[effective-open-flip]`、run 37431493935、flutter-textfield × MS-IME 8 回):**
1. フォーカス取得時の `[ImmCrossProbe] child-hwnd IME=false → High confidence 観測記録`(Flutter の子窓 `FLUTTERVIEW` に対する cross-process 読みが false)が 1 件だけ記録される。`expires_at: None` で残り続ける。
2. 打鍵中は `Skipping observer/SSOT write: typing active` で ObserverPoll(IME=true、Medium)の書き込みが止まる。最後の書き込みから 3.0s(`OBSERVATION_FRESH_WINDOW_MS`)後に `derive_any` が None になる。
3. フォールバックの `most_recent_trusted`(`observation_store.rs`)は `confidence` を先に、`at`(新しさ)を後に比べるため、古い High(false)が新しい Medium(true)に勝つ。実効値が false になり `Engine deactivated (ime=false, reason=Inactive(ImeOff))`。
4. 次の観測が入るまで約 28ms、親指キー(変換/無変換)が `PassThrough` になり MS-IME へ届いて入力モードが切り替わる(全角英字・カタカナ化、出力途中の文字が生キーになる)。
- 反転 26 回中 26 回が `→ false decided_by=MostRecentTrusted(ImmCrossProbe)`。GJI では 0 件(ImmCrossProbe が true、または記録されない)。wx・Qt では 3s 超の観測の空きがあっても反転しなかった(同じ空きで ImmCrossProbe(false)が無いため)。

**修正の候補(未決、ADR 起票と Opus 敵対レビューが先):** (A) `most_recent_trusted` を、鮮度が尽きた観測同士では新しさを先に比べる。 (B) 子窓に自前の IME コンテキストが無い入力先の ImmCrossProbe(false)を High として記録しない/Medium に落とす。 (C) ImmCrossProbe に有効期限を付ける。影響範囲は belief 全体なので、(A)(C) は journal リプレイで他の入力先の belief が変わらないことの確認が要る。

**次の手順:** 上の候補から方針を決め ADR を起票 → opus-adversarial-consult で収束 → 修正と回帰テスト(`[effective-open-flip]` の再現を journal リプレイに足す)。診断ログ `[effective-open-flip]` は PR #537 に入っている。
