# BUG-189: Flutter × MS-IME で打鍵の途中から全角英字・カタカナに化ける（未調査）

**状態(2026-10-06):** CI で再現(awase あり 4 回中 3 回 FAIL)。**原因は未調査**。GJI は 4 回とも PASS、awase なしの対照(tsx-raw-ext-flutter-textfield-*)は GJI・MS-IME とも 4 回 PASS。

**再現(CI):** ブランチ `ci/e2e-java-office` の run 37425162897(構成 `tsx-ext-flutter-textfield-msime-20ms`、`tools/e2e/input_forms/forms.toml` の `flutter-textfield`)。
Flutter for Windows の TextField(`tools/e2e/input_apps/flutter`)へ MS-IME・awase ありで 20ms 間隔の NICOLA を注入し、UIA で読み戻す。

**症状:**
- 試行の途中から出力が全角英字(期待 `…ねそせくせへひらて` → 実際 `…かねｍぎｇｂｘｙｄ`)やカタカナ(`あぱわの…` → `アパワノ…`)になる。IME の入力モードが途中で切り替わっているように見える。
- 失敗は thumb・mixed の試行が多く、single は崩れない run もある。run ごとに崩れる試行数が違う(2〜4/12)。
- 別 run(37423541905)では ready の 1 文字が `かかか` と重複した。

**手がかり:** awase.log には focus 分類のタイムアウト(`classify_focus timed out`、Flutter 窓)が出るが、失敗 run だけの特徴かは未確認。IME モードキーの送信有無・conv mode の遷移は未調査(journal の SentInput〈PR #468〉で送信列を見られる)。

**次の手順:** (1) 失敗 run の journal で、崩れた試行の直前の送信列と conv mode を確認する。(2) Flutter の実機(ユーザー環境)で再現するか確認する。(3) 対照が PASS なので awase の IME 状態の追随・actuation を疑って切り分ける([ime-belief-architecture](../../.claude/rules/ime-belief-architecture.md) の規約に従う)。
