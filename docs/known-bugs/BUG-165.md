# BUG-165: pending_deferred 上限超過で高速打鍵の文字が消える

**症状:** `ts-tsf-gji-2ms`（2ms 間隔打鍵）で、8 回に 1 回、182 文字が消えた。BUG-038 と同じ defer/replay キュー系統。

**原因:** `TsfWarmupCoordinator::DEFERRED_QUEUE_CAP = 32`（暫定値）を超えると、超過分は defer されず通常送信へ degrade する。
cold probe 中の直接送信は文字が消え、キュー内の分を追い越しもする。2ms 間隔なら 64ms で 32 VK に達し、cold probe（最大 ~960ms）の間に必ず超える。

**修正:** 上限を暴走防止の安全弁に位置づけ直し 32→2048。導出: 960ms × 500 key/s × 3 VK ≒ 1440 VK に余裕。probe は deadline で終わり flush される。
回帰テスト: `output/mod.rs::defer_vk_if_probe_in_flight_keeps_deferring_past_the_old_cap_of_32`（windows-build CI で実行）。

**未検証:** 実機/CI の `ts-tsf-gji-2ms` での消失ゼロ確認。
