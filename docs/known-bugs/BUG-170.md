# BUG-170: 予測でbeliefがONになってもGjiFsmへImeOnが届かない

**症状（report `01M3NBQA8KH2JN6S1PYHP8DJRF`、2026-09-29、GJI、msedge.exe/`Chrome_WidgetWin_1`/`Imm32Unavailable`、Google Meet）:** 「これでいい」→「でいい」。「時々消える」。

**journal（elapsed_ms）:** `201798` Edgeフォーカスで`GjiFsm`は`OffCold`。`203698` 物理`0xF2`→`KeyEffectPredicted{open:true}`だが、engine起案のSetOpenは`Unwarranted`
（awaseはIMEへ書かない設計、chain空）で終わり`GjiEvent::ImeOn`が誰からも発行されない。`203901`以降のR/親指打鍵は`GjiFsm=OffCold`の`pass_through`のまま、
`StartComposition(candidate SHOW)`が`OffCold`で観測される（=実GJIはON）。F2〜最初のRは約200msでcold-start待機なし。
**原因（推定、実機再現は未実施）:** 予測経路（`kp_predict_key_effect`）はbeliefだけを動かし`GjiFsm`に通知しない。BUG-18（`presync_applied_open_on`）と同型。BUG-156（`applied`側）は別軸。
**修正:** `kp_predict_key_effect`で`open==Some(true)`かつGJIなら`gji_on_ime_on`を呼ぶ（`ImeOn`は既にONなら no-op）。OFF方向は今回対象外。
**回帰テスト:** `architecture_guard::key_effect_prediction_open_true_notifies_gji_fsm`（ソース走査、Linuxで走る）。実機（Meet/Edge）での確認は未実施。
