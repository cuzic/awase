# BUG-188: TsfNative の外部クローズ後に Engine ON × IME 閉の drift

**状態(2026-10-05):** 未修正(CI で再現、ADR-227 D0-5 の実測。ADR 棚卸しの Opus レビューで未起票と判明し起票)。

**症状:** Windows Terminal 1.23・GJI・`profile=TsfNative` で、外部から IME を閉じる(`WM_IME_CONTROL` の `IMC_SETOPENSTATUS`)と、
+0.3/+1/+4.5 秒の打鍵が全て生ローマ字 `kiu`(NICOLA の `き`,`う` を awase が romaji `ki`,`u` で送り、閉じた IME が literal で受ける)になる。
`giveup=0 suspected=0` で文字は消えず、belief(ON)・Engine(ON)は閉じたまま追随しない。

**再現:** run 37237143414、`cal-d0-gji-wt-close-follow`(8 試行)。awase なしの対照 `cal-d0-gji-wt-close-control`(5 試行)は `ka`(閉)で外部クローズ自体は効く。

**注意:** 閉じた IME の conv に NATIVE ビットが残る(`conv=0x19`、`open_after=0`)ため、推論追随は `idle-conv-check` の `ConvOpenInference` に打ち消される恐れ(ADR-227 B1)。
BUG-074 の `give-up` 読み直し(PR #480)は TsfNative では発火しないので効かない。
