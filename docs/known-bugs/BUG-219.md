# BUG-219: 打鍵中に belief が約 1 秒 OFF に倒れ、その間の NICOLA 打鍵が素通りする

**状態(2026-10-25):** 未修正。原因の経路のうち「共有メモリの期限切れ」は確定、「古い ObserverPoll=false の書き手」は未確定。

**症状:** dragonflyg4(Mozc Readable、Chrome)で「かんけいできますか？」と打つと「かんけいできますw１」になった(2026-10-25 17:49 JST)。末尾の「か」「？」が NICOLA の W・`1` のまま IME に入り、`w` は子音待ち、`1` は全角「１」。

**ログ(`awase.log.old`、08:49 UTC)で確かめた流れ:**
- 04.340 `[skip-typing-read] ime_on=Some(false) conv=0x19`(IMM の読みは「閉」。conv=0x19 はひらがなで、実際は ON。IMM の嘘)。
- 04.475 `effective-open-flip → false decided_by=DeriveMedium{ObserverPoll}`。Engine が `deactivated (ImeOff)`。
- 04.582 / 04.815 W と `1` が `decision="PassThrough"`(belief が OFF の間の打鍵)。
- 05.476 `[mozc-shm] follow external change open=true effective_was=false` → 05.623 `flip → true decided_by=DeriveHigh(MozcShm)`。OFF は約 1.15 秒。
- 同じ「OFF へ倒れて約 1 秒後に MozcShm が戻す」が 17:48:50 / 48:53 / 49:00 / 49:04 に繰り返された。
- 17:46〜17:50 の W・`1` の素通り(KeyDown)は 9 回。うち belief の OFF が `ObserverPoll` 由来なのは 3 回(49:00.729 の W、49:04.582 の W、49:04.814 の `1`)。3 回は `ExplicitIntent` の OFF(意図した IME オフ)、残り 3 回(47:02〜47:11 の W)は belief が ON のまま素通りで別原因(未調査)。

**原因(確定した部分):** `resolve_open_at` は High が無いと Medium の単独(`DeriveMedium`)を採る。`MozcShm`(High)は `MOZC_SHM_OBSERVATION_TTL_MS=1000` で失効し、Mozc の状態が変わらず再読込も無いと 1 秒で High が消える(ADR-268 の status が「TTL=1000ms は不足、tick 間隔 1000ms 超が 8.8%」と既知)。High が消えた瞬間に、新鮮(3 秒以内)な `ObserverPoll=false`(Medium、IMM の嘘)だけが残り、belief が OFF になる。
**未確定:** その新鮮な `ObserverPoll=false` を書いたのが `ir_follow_external_change` / `follow_direct_read`(`ime_refresh` 経由)なのか別の経路なのか。ログに書き込みの行が無く、特定できていない。

**窓の種類別の集計(`awase.log.old`+`awase.log` 全体、`ObserverPoll` 由来の OFF 反転 12 件):** Chrome 3 件・LINE(Qt)5 件は全て 5 秒以内に MozcShm が ON へ戻した(8/8 が誤り)。Zoom・DirectUI・フォーカス移動中の 4 件は MozcShm の報告が無く正誤不明。サンプルは 1 台 12 件で、窓の種類は直前の `FocusChange` から割り出した近似。

**直し方の候補(未着手):**
- (所有者の指摘 2026-10-25)`ObserverPoll=false` の信頼度を窓のプロファイルで変える。IMM が読めない・信頼できない窓(`Imm32Unavailable`・`TsfNative`)の IMM 由来の読みは Low に下げる。GJI の I/O 観測(`observe_gji_after_focus`)は対象外(その窓で GJI 利用者の唯一の証拠のため)。
- 「直前に High で確認した値」を、別の High が来るまで Medium 単独が覆さないようにする。TTL 切れを「分からない」にしない。
- 打鍵中(idle が短い間)は Medium 単独の OFF 反転を保留する。方針は「belief より利用者の打鍵の意図を優先する」(2026-10-23)と整合する。
- 字形(タスクバーのインジケーター)は今回は読まれていない(前面の窓が変わったときだけ読む・観測のみ)。17:49:09 の読みは `kana`(ON)で実状態と一致。倒す前の拒否権に使う案は第二の守り。

**関連:** BUG-218 の「限界・別件」(Mozc が閉と報告しても ON のまま)は逆向きの同根。`ime_refresh` が打鍵中を理由に観測を飛ばす点も共通。再現は未了(擬似窓で MozcShm の失効と IMM の嘘を再現するのが次)。
