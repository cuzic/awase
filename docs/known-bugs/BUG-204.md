# BUG-204: 仮定の既定のかなの種を belief に書き、観測したモードと区別できない

**状態(2026-10-18):** 未修正。閉ループのランダム探索(PR #634)で再現。実機の実害は未確認。フォーカス移動の件は読解のみで再現していない。

**症状(CI の擬似 IME):** ATOK で IME が閉・半角英数(conv 0x10)で始め、belief の入力モードが Unknown のとき、最初の打鍵(閉のまま押す表に無いキー・閉→閉のキーでも)で `AssumedRomaji{KeyEffectPrediction}`(かな)が belief に入る。続く IME を開く打鍵は `mode: None`(変えない)なので、かなのまま残り、実 IME は 0x10(半角英数)で開く。想定される実害は、半角英数で開いた IME に NICOLA のローマ字が送られること。

**再現:** `crates/awase-windows/tests/closed_loop_scenarios.rs::random_key_walks_keep_predictions_consistent_with_truth` の `EXPECTED_SEEDED_GAP`(32 件 / 2878 打鍵。ATOK・閉・半角英数で始まる 16 シード × 窓 2 通り)。件数は固定してあり、直すと 0 に下がる。

**原因(読解):** `predict_in_table`(`key_effect_predictor.rs`)が `seeded`(入力モードが Unknown)のとき `kana_mode()` を効果に入れる(表に無いキーの分岐と `or_else(|| seeded.then(kana_mode))`)。種は意図した設計(`unknown_mode_is_seeded_with_kana_so_prediction_can_start`)だが、belief に書くと観測と区別できない。閉の間は conv から入力モードを作らない(BUG-57 / ADR-239)ので、閉のまま開くまで観測で直らない。

**実測(格子 `tools/e2e/ime_key_matrix/grid-tables/`):** 閉→開は ATOK 10/10・GJI の MS-IME プリセット 18/18 で閉じる前の変換モードを復元する。MS-IME 本体は 閉 c10 から開くと 0x19(格子の 7 キー)。ただし試行は各セル 2 回以下(MS-IME 本体は 227 セル中 206 が 1 回)で、決定的とは言い切れない。

**方針案(未決):** (a) 種を表を引くための conv の選択にだけ使い、belief には書かない。(b) 閉→開で `after_conv=None` のとき、belief が仮定の種なら「変えない」ではなく Unknown を返す(`PredictedEffect.mode` の `None` が「変えない」と「不明」を兼ねている点を型で分ける)。閉の conv(`conv_raw`)から種を取る案は MS-IME 本体で外れる(上の実測)。belief の領域なので、直す前に ADR で方針を決める。

**関連(未再現):** `ImeModel::reduce_focus_changed`(`ime_model.rs`)は `key_track`・`key_effect`・`applied` を消すが `input_mode` を消さない。新しい窓の IME が閉のとき、開く打鍵の「変えない」は前の窓のモードを残す疑い。ランダム探索にフォーカス移動が無いので現れない。半角英数トグルの戻り待ち(ADR-245)と絡む可能性。

**修正履歴:** なし。
