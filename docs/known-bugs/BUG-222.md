# BUG-222: 自動の半角英数のあとの F2 で、実 IME は hiragana になるのに Engine が inactive のまま

**状態(2026-10-26):** 原因はコードの読みで特定、所有者決定で自動の入りに限って修正を PR にした(実機は未確認)。

**症状:** dragonflyg4(Google 日本語入力〈GJI〉、tsf-native 窓。起動時は Mozc Readable だったが 03:25〜03:46Z の間に GJI へ切り替え、F2 のログ 03:53〜03:58Z は GJI)で lang-detect が半角英数に入った後に F2(ひらがな)を押すと、実 IME は hiragana になるが awase は `ObservedEisu`・`toggle_held` 真のままで、NICOLA が効かない(ログ: F2 6 回とも `no prediction`、1 秒以内の `Engine activated` なし)。窓切替のときだけ戻る。

**原因(コードの読み):** F2 で戻れる 4 経路が全部塞がっていた。(1) `shadow_action` が無く TurnOn 救済(`key_pipeline.rs` の `eisu_reset_on_turn_on_while_open`)に届かない、(2) GJI は config1.db の表で F2 を予測できるが、トグル中は追跡を捨て(ADR-244 M-2)、入力中の段階が「不明」(入力中の BS の後、BUG-211)だと表にセルが無く予測なしになる(特性テスト `bug_222_f2_has_no_prediction_in_the_indeterminate_stage_for_gji_tables`。実機の原因は断定できていない。予測が付いても `toggle_held` は手放されない)、(3) 直接観測は Imm32Unavailable の窓に限り(tsf-native は対象外)、対象でも GJI は手放さない(`should_abandon_on_observed_follow` は MS-IME のみ)、(4) `eisu_reset_on_ime_on` は閉→開の遷移でしか動かない。

**修正(所有者決定):** lang-detect が入れたトグル(`entered_by_lang_detect`)に限り、tsf-native × GJI 系(Mozc を含む)で、素の物理 F2 の KeyDown をトグルを出る契機にする(OS 書き込みなし。belief を `AssumedRomaji` へ、`UserTurnOnEisuReset`)。左 Shift 単独タップの手動のトグルは変えない(`024ca336`→`6b1e91b8` の取り下げ、`docs/experiments.md`)。窓の離脱で由来は消える(戻り待ちには引き継がない)。実 IME が応答しなかったときの検知は `[lang-detect-exit]` のログ(手放した時点の conv_raw)と後続の `[idle-conv-check]` の conv(Mozc なら `[mozc-shm]`)。

**回帰テスト:** `half_width_alnum.rs::bug_222_f2_exits_the_lang_detect_toggle`・`bug_222_manual_toggle_is_not_exited_by_f2`(対照)・`bug_222_f2_exit_conditions`。
