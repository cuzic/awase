# BUG-222: 自動の半角英数のあとの F2 で、実 IME は hiragana になるのに Engine が inactive のまま

**状態(2026-10-26):** 原因はコードの読みで特定、所有者決定で自動の入りに限って修正を PR にした(実機は未確認)。

**症状:** dragonflyg4(Mozc Readable、tsf-native 窓)で lang-detect が半角英数に入った後に F2(ひらがな)を押すと、Mozc は hiragana になるが awase は `ObservedEisu`・`toggle_held` 真のままで、NICOLA が効かない(ログ: F2 6 回とも `no prediction`、1 秒以内の `Engine activated` なし)。窓切替のときだけ戻る。

**原因(コードの読み):** F2 で戻れる 4 経路が全部塞がっていた。(1) `shadow_action` が無く TurnOn 救済(`key_pipeline.rs` の `eisu_reset_on_turn_on_while_open`)に届かない、(2) トグル中は追跡を捨てる(ADR-244 M-2)ため予測が付かない(表による)、(3) 直接観測は Imm32Unavailable かつ Mozc 以外に限る(#840)うえ、GJI は手放さない(`should_abandon_on_observed_follow` は MS-IME のみ)、(4) `eisu_reset_on_ime_on` は閉→開の遷移でしか動かない。

**修正(所有者決定):** lang-detect が入れたトグル(`entered_by_lang_detect`)に限り、tsf-native × GJI 系で、素の物理 F2 の KeyDown をトグルを出る契機にする(OS 書き込みなし。belief を `AssumedRomaji` へ、`UserTurnOnEisuReset`)。左 Shift 単独タップの手動のトグルは変えない(`024ca336`→`6b1e91b8` の取り下げ、`docs/experiments.md`)。窓の離脱で由来は消える(戻り待ちには引き継がない)。実 IME が応答しなかったときの検知は `[lang-detect-exit]` のログ(手放した時点の conv_raw)と後続の `[idle-conv-check]`・`[mozc-shm]`。

**回帰テスト:** `half_width_alnum.rs::bug_222_f2_exits_the_lang_detect_toggle`・`bug_222_manual_toggle_is_not_exited_by_f2`(対照)・`bug_222_f2_exit_conditions`。
