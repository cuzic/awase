# BUG-184: 英数キーによる IME OFF で未確定文字が消える(MS-IME)

**症状:** MS-IME・TSF アプリ(Chrome)。文字未確定のまま英数キーを押すと未確定文字が消える。
確定したうえで OFF にしてほしい(報告者の要望)。

**報告:** `01M3VCRSS2BEXGPKH2S8BYCX30`(1.21.0、2026-10-01)。

**確認できたこと(journal、経過 2222779ms の OFF):** 直前 0.3 秒まで親指シフトの打鍵が `Consume` され
romaji が IME に送られていた。物理 英数(0xF0)は `Suppress(imm-cross)`、awase が
`ImmCross SetOpenThenConvForTarget{open:false}` で閉じている(`AppliedWithoutSendInput`)。OFF 11 回すべて同経路。
OFF の前に未確定文字を確定する処理はコード全体に無い(`CPS_COMPLETE` 等0件)。
素の MS-IME の英数キーは未確定文字を半角英数に変換して残す動作のため、Suppress が差を生む可能性がある。

**未確認:** `ImmSetOpenStatus(FALSE)` で未確定文字が実際に破棄されること。app_log の `composition_active` は
全 OFF で false(TSF アプリ内の未確定を検出できていない)。BUG-168/170/171 は GJI 側の別機序。

**次の一手:** 実機で「未確定→英数」を、素の MS-IME・awase 有効それぞれで比較する。
修正案は OFF 前の確定(`ImmNotifyIME(CPS_COMPLETE)` 等)か、英数キーを Suppress せず OS へ通す。

**修正履歴:** なし(未対応)。
