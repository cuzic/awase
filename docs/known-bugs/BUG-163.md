# BUG-163: 起動直後の `desired_open=true` 初期値による強制IME ON

**発見経緯:** 2026-09-24 俯瞰レビュー B-5(起動時の強制ON部分)。BUG-157 が「develop 版CIにも同数ある起動直後の既存の
過渡現象」として切り出したまま、どのBUGにも追跡されていなかった現象。詳細な調査・設計案は
[docs/tasks/review-2026-09-24-05-startup-desired-open-forced-on.md](../tasks/review-2026-09-24-05-startup-desired-open-forced-on.md)。

**症状:** IMEを閉じた状態でawaseを起動すると、起動直後に `[drift] correction: observed=… ≠ desired=true …
set_ime_open(true)` が約11秒間に22件出る(BUG-157 記載。CI run 35620809258 `ci/e2e-drift-fix` の `real-sc-dbe`
awase.log)。awaseがIMEを開けに行く挙動で、ADR-191 決定1(IMEが状態の正、awaseは書かない)に反する。

**原因(コード上の確認、`5877f982` 時点):**
- `state/ime_model.rs:309` `ImeModel::new()` が `desired_open: true`。根拠だった `ImeBelief.ime_on` は現存しない。
- `state/platform_state.rs:1091` `check_drift_correction` の抑止は「観測源が ConvOpenInference/HeuristicDefault かつ
  明示意図なし」と「観測==desired」のみ。起動直後に ImmCrossProbe 等が「閉」を観測すると初期値 true と比較され発火する。
- 送信は `runtime/ime_refresh.rs:645` `ir_apply_drift_correction`。

**未確認:** 22件が再送の結果か(約500ms間隔、推測)、読める窓(ImmCross)の実機で実際にIMEが開くか、
Confirmedで収束するか。CIログ・実機(GJI/MS-IME × メモ帳/Chrome、実打鍵で確認)での確認が必要。

**再現(CI):** run 35620809258 の `real-sc-dbe` で起動〜最初の `VK_IME_OFF` までの `[drift] correction` 件数を数える。

**修正方針(未着手、推奨は代案A):** ADR-187 追補4 の `ModeKeyPassedThrough { align_desired }` と同じ揃え機構を
起動直後(awase未書き込み・明示意図なし)の最初の成功観測にも適用。`desired_open` の型・初期値・
`effective_open()` のフォールバックは変えない。テストは純関数(Linux)と `platform_state`(windows-build CI)の2段。

**追記(2026-09-25、CI実測。現在のdevelopでも再現):** windows-latest・GJI+ATOK、`f2a875cd`（run
[36103384502](https://github.com/cuzic/awase/actions/runs/36103384502)、`baseline`×3・`atok-passthrough-cold`×3。検証専用ブランチ
`ci/verify-05-startup-drift`）。全6回で、起動0.5秒後と約1秒後（回により3件目も）に、明示意図なし（`explicit_intent=None`）の
`[drift] correction: observed=false ≠ desired=true … set_ime_open(true)`（源=ImmCrossProbe/High、`attempts=0,1(,2)`）が出た。
その後は止まり（観測は閉のまま＝書き込みは効かない）、ハーネスの操作後のフォーカス変更で1件再発する。**上の「約11秒に22件」は現在は
再現しない**（旧run 35620809258 の3構成は22/19/22件、観測源は ObserverPoll/Medium、`attempts`は21まで増加）。件数は起動後の観測源の違いで
変わるので、「最大N回」とは書かない。同じ起動直後に awase 自身が `VK_IME_OFF→VK_IME_ON`（`[gji-fsm] Unicode long-cold StartProbe`）を
送る（warmup、例外として維持する経路）ことも確認した。実機での影響は未確認のまま。

**修正履歴:** なし(未修正)。
