# BUG-135: ADR-121のVK_IME_ON冪等再送、即時パスがpending_explicit_reassertラッチを解除せず冗長送信しうる（クローズ）

**クローズ（2026-09-23、コード監査で確認）:** 本バグが対象にしていた
`reassert_explicit_physical_key`／`pending_explicit_reassert`ラッチ
機構（ADR-121 D1）自体が、2026-09-18のADR-178領域A撤去
（`f83084b3`「teardown(tsfnative-rescue): ADR-121 D1 reassert機構を撤去」）
で完全に削除された。`peek_pending_explicit_reassert`/
`disarm_pending_explicit_reassert`/`set_pending_explicit_reassert`/
`reassert_ime_apply_complete_without_belief_write`/
`reassert_explicit_physical_key`のいずれも現存しない
（`grep -rn reassert_explicit_physical_key`が本文コメント以外に
ヒットしない）。ラッチが二重に残るという本バグの症状は、ラッチ機構
そのものが無いため構造的に発生し得ない。コード修正は不要。

**元の症状（当時の記述の要旨、コード監査で発見・実機未確認のまま）:**
ADR-121 D1（PR #188）のVK_IME_ON冪等再送で、フォーカス遷移settling中の
`pending_explicit_reassert`ラッチを即時実行パスが解除し忘れ、後から
発火するタイマーが冗長な`VK_IME_ON`再送を起こしうる、という指摘
だった。D1機構自体が撤去された今、この経路は存在しない。
