# BUG-186: Shift 面の全角ラテン文字が半角英数入力と混ざる

**状態(2026-10-04):** 修正済み(CI で確認待ち)。

**症状:** GJI × 実 Chrome、IME ON(かな)で Shift を押しながら `a`,`b` を打つと `ＡB`(awase なしは `AB`)。
`layout/nicola.yab`・`nicola_keytop.yab` の `[ローマ字小指シフト]` が `Ａ`〜`Ｚ` を全角で持ち、
`shift_face_reduce` がそれをそのまま Unicode 注入していた。.yab に定義の無いキーは素通しで半角になるため、
同じ Shift 押下中でも文字ごとに全角・半角が混ざる(報告「ブラウザでの英数入力が不安定」の再現 CI、
`sc-alnum-gji`、run 37229505043)。

**修正:** `shift_face_reduce` で、Shift 面の全角ラテン文字(`Ａ`〜`Ｚ`・`ａ`〜`ｚ`)だけ半角 ASCII にして出す。
記号(`！` など)は従来どおり .yab の値。回帰テスト: `src/engine/tests.rs::test_shift_face_fullwidth_latin_letter_becomes_halfwidth`。

**未確認:** MS-IME の挙動(CI の `sc-alnum-msime` は前提状態を作れず INVALID が多く、判定できていない)。
