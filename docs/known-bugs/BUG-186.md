# BUG-186: 半角英数持続トグル中の IME 側モードキーで Engine が戻らない

**状態(2026-10-04):** 修正済み(CI 確認待ち)。報告「ブラウザでの英数入力が不安定」の再現 CI(`sc-table-*`)で発見。

**症状:** 実 Chrome × MS-IME 本体(GJI MS-IME プリセットでは変換でローマ字のまま)。左 Shift 単独タップで持続半角英数にしたあと、
変換・英数・ひらがなを押すと IME はかなに戻るが、Engine は OFF のままで NICOLA の代わりに `か`(IME 側のローマ字かな)が出る。
IME_ON キーは `kp_restore_kana_from_half_width` に委譲済みで正常。直接入力・かな・半角英数の 3 状態からは全キーで一致(2 周とも同じ結果)。

**原因:** トグル中は OS の読み取りを凍結している(`ime_refresh.rs`・`kp_stage_idle_conv_check_inner`)。IME 側のモードキーは素通しで
`kp_stage_mode_key_follow` が読み直しを予約するが、凍結中なので観測が belief に届かない。

**修正:** `kp_stage_mode_key_follow` で、トグル中に素通しのモードキーが来たらトグルを OS 書き込みなしで手放す
(`HalfWidthAlnumState::abandon_for_mode_key`)。回帰テスト: `abandon_for_mode_key_clears_toggle_without_a_restore_request`(状態の単体)。
実 Chrome での効果は `sc-table-msime-*` の「Shift単独タップ後」行で確認する。
