## Note(収束を妨げない文言の残り)

### N11. 決定4 の表の右列が、直前の注意書きと食い違ったまま

表の前の段落は「表の『awase 上の扱い』は `key_role` の結果で、実際の扱いは下の条件で変わる」「『Suppress して `VK_IME_ON/OFF` を送る』も
`transport.rs::plan` の条件次第で、言い切れない」としている。それなのに、表の1行目のセルは「能動(awase が Suppress して `VK_IME_ON/OFF` を送る)」、
2行目は「(エンジン非活性側でも Consume + 絶対 `SetOpen`)」と言い切ったまま残っている。

列見出しを「`key_role` の結果」にし、セルを「`ImeToggle`(能動の候補)」「`None`(受動)」のように結果だけにする。
括弧内の awase の挙動は上の条件の段落へ移す。

### N12. `config1.db` が読めない構成では、決定6 の import 後の確認もできない

決定1 で「読めない → エクスポート必須」にしたが、その構成では import 後に `config1.db` を読み直す決定6・決定7 末尾の確認も成り立たない。
UI は「確認できません(`config1.db` を読めないため)」と出し、失敗とも成功とも表示しない、と一文足すとよい。
